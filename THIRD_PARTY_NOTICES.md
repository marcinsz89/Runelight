# Third-party components

## ColorPickerView 2.3.0

Copyright 2017 skydoves (Jaewoong Eum).

Native color wheel reused from [skydoves/ColorPickerView](https://github.com/skydoves/ColorPickerView),
licensed under Apache License 2.0. The pinned version uses the existing Android
Views stack without a toolchain or Compose migration. Runelight supplies its
own selector, inline editor, preview animation and settings ownership; it does
not use the library's dialog or automatic preference persistence.

The license ships in `app/src/main/assets/licenses/colorpickerview-LICENSE.txt`.
Runelight's original GPLv3 licensing and upstream attribution remain in effect.

## Poppins

Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins).

Regular (400) and Bold (700) are bundled from the
[Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/poppins)
under the SIL Open Font License 1.1. The unmodified font binaries ship locally;
the app does not download fonts at runtime. The complete license ships in
`app/src/main/assets/licenses/poppins-OFL.txt`.
