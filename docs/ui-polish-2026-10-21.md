# Surface and motion refinement — 2026-10-21

Scope: refine the existing lower-screen layout in place. Retain the original
mockup as a reference and keep the current controls, order, gestures and editor.

## Appearance

- Static violet/graphite background gradient in dark mode; lavender/white in light.
- Shallow card gradients and fine borders, with a richer active violet gradient.
- Separate selected-effect colors for each appearance. Text contrast through the
  interpolated fill is at least 10.54:1 in light mode and 6.08:1 in dark mode.
- Cached color/Speed tile gradients: a 10% white highlight, original color and
  14% black shade. Fall back to the original color at an endpoint if shading
  would lower label contrast below 4.5:1. LED colors/output processing are unchanged.
- Remove the main tiles' secondary instructions; retain action/unavailable
  accessibility descriptions. Keep 110dp minimum tile bodies after subtitle removal.
- Add 6dp gaps between the inline color editor's Copy, Cancel and Apply buttons.

## Motion and state

- Effect fill/edge transitions: 180 ms, preserving Material button shapes,
  native ripples, checked state and accessibility semantics.
- Tile press: 80 ms compression; release: 160 ms. Activation adds a small violet
  shadow and a 160 ms gradient fade. No repeating animation or idle redraw loop.
- Custom transitions check Android animation enablement; native property animators
  follow the system duration scale. Finish effect tint transitions on Stop/Destroy
  of the UI lifecycle. Appearance recreation binds current state without an entrance fade.
- Fixed an On/Off blink: a plain-effect replacement previously published Starting
  even while the old frame remained lit. `LightingRuntime` now holds the last
  acknowledged Running effect until the new session accepts its first frame.
  Generation fencing, failure and the five-second first-frame deadline still apply;
  cold starts cannot claim held output. Stop invalidates the pending effect.
